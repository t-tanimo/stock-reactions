# Stock Reactions

## 概要

Stock（stock-app.jp）のメッセージに、**🙏 ありがとう** と **✅ 対応済み** のリアクションを追加する Chrome 拡張機能です。

## できるようになること

### 「ありがとう」「対応済み」ボタン

メッセージにマウスを乗せたときの操作ボタン列で、「了解しました」の右に **🙏 ありがとう** と **✅ 対応済み** が並びます。

```
↩ 返信   ✓ 了解しました   🙏 ありがとう   ✅ 対応済み   ☺ リアクション   💬 未読に戻す
```

- 押すと、元のメッセージの下にバッジが付きます（例: `✅ 対応済み 2`）
- バッジにマウスを乗せると、押した人の名前が出ます
- 自分が押したバッジは青色で表示されます。もう一度押すと Stock の「削除してもよろしいですか？」が出て、OK で取り消せます
- 他の人が付けたバッジを押すと、自分も同じリアクションを付けられます
- 自分の投稿やシステム通知など、「了解しました」が出ないメッセージにはボタンも出ません
- Stock Plus の「対応します！」ボタンと一緒に使えます

### 拡張機能を入れていない人からの見え方

Stock のリアクションは種類がサーバー側で決まっていて追加できないため、この拡張機能はボタンを押すと**短いメッセージを送信**し、それをリアクションとして表示しています。

| 見る人 | 見え方 |
| --- | --- |
| 拡張機能を入れている人 | 送信されたメッセージは隠れ、元のメッセージの下にバッジで表示 |
| 入れていない人（スマホアプリ・デスクトップアプリを含む） | 普通のメッセージとして表示（下の例） |

```
✅ 対応済み
> 野元竜輝さん「タスク「回答」を完了しました」
```

- どのメッセージへのリアクションかは、見えない文字でメッセージに埋め込んでいます
- 通常のメッセージなので、他のメッセージと同じく未読・通知の対象になります
- 押す前に送信欄へ書きかけていた文章は、送信後に元に戻ります

## 導入の仕方

コマンド操作は不要です。ZIPをダウンロードして展開し、Chromeに読み込むだけで使えます（所要3分程度）。

Chrome ウェブストアには公開していないため、「デベロッパーモード」での読み込みになります。Chrome / Microsoft Edge で利用できます。

### 1. ZIPをダウンロードする

1. [リリース一覧](../../releases) を開きます
2. 一番上（最新）のリリースの **Assets** を開き、**Source code (zip)** をクリックします

### 2. ZIPを展開して、置き場所を決める

1. ダウンロードしたZIP（例: `stock-reactions-1.0.0.zip`）をダブルクリックして展開します
   - macOS: ダブルクリックで同じ場所にフォルダができます
   - Windows: 右クリック →「すべて展開」
2. できたフォルダ（例: `stock-reactions-1.0.0`）を、ずっと置いておける場所に移動します
   - 例: `書類（Documents）/stock-reactions-1.0.0`

> ⚠️ **このフォルダは削除・移動しないでください。** Chromeは読み込んだフォルダを直接参照し続けるため、消すと拡張機能が動かなくなります（ダウンロードフォルダのままにしておくと、掃除で消してしまいがちなので注意）

### 3. Chromeに読み込む

1. Chromeのアドレスバーに `chrome://extensions` と入力して開きます
2. 右上の「**デベロッパーモード**」をONにします
3. 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします
4. 手順2で移動したフォルダ（`manifest.json` が直接入っているフォルダ）を選択します
   - フォルダの中を開くと `manifest.json` が見えるはずです。開いた先にもう一段フォルダがある場合は、その内側のフォルダを選んでください
5. 一覧に「**Stock Reactions**」が表示されれば完了です

### 4. 使い始める

Stock（stock-app.jp）を開きます。すでに開いている場合はタブをリロードしてください。

メッセージにマウスを乗せると「🙏 ありがとう」「✅ 対応済み」が表示されます。

## アップデートの反映

新しいバージョンが出たら、以下の手順で入れ替えてください。

1. 手順1〜2と同じように、新しいZIPをダウンロードして展開・移動します
2. `chrome://extensions` を開き、古い「Stock Reactions」の「削除」をクリックします
3. 「パッケージ化されていない拡張機能を読み込む」で、新しいフォルダを選択します
4. Stockのタブをリロードします
5. 古いフォルダは削除して構いません

> 📌 付けたリアクションはStock上のメッセージとして残るため、入れ替えても消えません。

## ディレクトリ構成

```
stock-reactions/
├── manifest.json   # Manifest V3
├── icons/          # 拡張アイコン（16/48/128px）
├── content.js      # ボタン追加・送信・バッジ表示
└── content.css     # 見た目
```

## 注意事項

- DOMセレクタは実際のStockのDOM（2026-11時点で実機確認済み）に合わせています。Stock側の画面が変わると動かなくなる可能性があります
- 送信はStockの画面の送信欄・送信ボタンを使って行います（Stockの外部へのデータ送信はありません）
